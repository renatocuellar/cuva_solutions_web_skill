# CUVA Solutions Web Skill

Skill de Claude creada por Renato Cuéllar para diseño web de alto nivel con arquitectura SILO para SEO y AEO.

## Estructura

- `cuva-solutions-web/SKILL.md`: instrucciones principales de la skill
- `cuva-solutions-web/references/`: guías de identidad, estructura, animaciones, calidad, competencia, SILO, SEO técnico y blog
- `cuva-solutions-web/assets/`: plantilla base, ejemplo de sitio y mapa de contenido
- `cuva-solutions-web/scripts/`: scripts para construir, revisar y auditar sitios

## Instalación

Descarga la carpeta `cuva-solutions-web`, comprímela en .zip y súbela en Claude, en Configuración > Capacidades > Skills.
