# CUVA Solutions Web Skill

Skill de Claude creada por Renato Cuéllar para diseño web de alto nivel con arquitectura SILO para SEO y AEO.

## Qué hace

- Recibe el brief de marca completo: historia, misión, visión, propuesta de valor, cliente ideal, servicios, tono, prueba y objetivos.
- Investiga competencia y búsquedas, y arma mínimo 5 silos.
- Pilares de 3.000 palabras o más y satélites de 1.500 o más.
- Cada pieza cumple las reglas de Rank Math y la arquitectura de URLs `/pilar/satelite/` de menos de 75 caracteres.
- Todo el contenido se escribe 100 % humano: voz del negocio, experiencia real y cero muletillas de texto automático.
- Diseño propio por marca con parallax de GSAP y ScrollTrigger: todas las imágenes se expanden suave al hacer scroll.

## Estructura

- `cuva-solutions-web/SKILL.md`: instrucciones principales de la skill
- `cuva-solutions-web/references/`: identidad, estructura y copy, animaciones (16.1 parallax), calidad, competencia, SILO, SEO técnico, blog, escritura humana y Rank Math
- `cuva-solutions-web/assets/`: brief de marca, plantilla base, ejemplo de sitio, mapa de contenido y demo del parallax
- `cuva-solutions-web/scripts/`: construir, revisar y auditar sitios (la auditoría revisa extensión mínima y pruebas de Rank Math)

## Demo del parallax

Descarga `cuva-solutions-web/assets/demo-parallax.html` y ábrelo en Chrome. Baja despacio para ver cómo cada imagen se expande y se mueve en parallax.

## Instalación

Descarga la carpeta `cuva-solutions-web`, comprímela en .zip y súbela en Claude, en Configuración > Capacidades > Skills.
